# Reef 剧本阅读器

更新日期：2026-10-26。本压缩包适用于 Apple Silicon（M 系列芯片）Mac，内含 arm64 本机翻译程序。

解压后，将整个 `script-editor` 文件夹导入 Reef 的 Renderer 设置。已安装的用户替换同一 renderer 的完整目录，保留包内所有文件，然后重新打开 `script.json`；若仍显示旧界面，退出并重新打开 Reef。

使用环境：

- 剧本阅读与视频关联：本机安装 Node.js 22 或更高版本。
- 生成人物原片参考：本机安装支持 `evidence` 命令的 scriptctl、FFmpeg（含 ffprobe），并关联与剧本分集对应的完整原视频目录。
- 台词翻译：macOS 26 及对应的本机翻译语言包。

压缩包包含 renderer 程序，不包含剧本、原视频、Node.js、scriptctl 或 FFmpeg。

- 故事梗概：全剧介绍、人物简介、分集梗概；点击集标题定位正文。
- 剧本：本集梗概开关；台词译文开关（Option+A）和目标语言选择。
- 人物：保留人物及造型卡片；点击造型上的“帧原片”查看对应三帧，人物识别照单独展示；点击图片放大或定位原视频。正文中悬停人物名可查看人物识别照。
- 原片参考：读取剧本旁 `evidence/state-evidence.json`，或客户端 `project.json` 指定的工作区。关联源视频后可点击生成或更新，使用本机 `scriptctl evidence`。
- 视频：点击带时间戳的 Action 定位原片，播放时跟随正文；支持连续分集、移动和缩放。
- 关联源视频：点击入口时查找当前关联、项目记录、来源项目及剧本附近目录，列出路径、示例文件名、匹配集数、缺集与多集。选择“关联此目录”后保存并立即加载视频；“手动选择文件夹”使用 Reef 的原生目录选择器。推荐依据目录来源与文件名中的集号，选择时核对剧名。查找不修改剧本。

翻译使用 macOS 26 的本机翻译。目标语言包括简体中文、英文、日文、韩文。缺少语言包时，点击“下载翻译语言”进入系统的语言与地区设置，安装后点击“重试翻译”。译文缓存保存在工作区 `.cache/dialogue-translation`；梗概和译文仅供阅读，不写回剧本。

需要 Node.js；抽帧还需要 PATH 中的 `scriptctl`、FFmpeg。启动器沿用登录 shell 的环境。阅读器为当前文档启动仅监听 `127.0.0.1` 的临时服务，使用随机会话地址处理本机翻译、图片、抽帧和视频关联；关闭预览后空闲 15 分钟自动结束。打开文档时的视频由 Reef 的本地资源协议加载；当前预览中新关联的视频通过会话服务流式播放，支持时间跳转。

源码位于 reef-renderers 仓库的 script-editor/。运行 npm ci 和 npm run build，产物位于 .reef-build/script-editor。
